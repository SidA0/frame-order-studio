FRAME ORDER STUDIO / TUTORIAL

Know what every button makes.

Start with a multi-body STEP or a cut list, review the tube rows, then choose the output that matches the job.

Your CAD stays on your deviceThe hosted app analyzes STEP files in your browser. It does not upload them. The SLDPRT button only records a file name as a reference; it does not read SolidWorks geometry.
01 / WORKFLOW

Three steps to an export

1

Load a source

Use Generate from frame STEP for a multi-body STEP. Use Import cut list for CSV or saved project JSON.

2

Review the geometry

Select a STEP body to see its drawing and detected profile. Use Add bodies to tube set to link the detected bodies into editable order rows.

3

Choose your deliverable

Use a ZIP for STEP bodies, an SVG for a single drawing, or the print buttons to save sheets as PDF through your browser.

03 / CONTROLS

What each button outputs

Load and start

Generate from frame STEP
Reads the selected multi-body STEP in the browser, separates its solids, analyzes tube profiles and bend flags, creates body drawings, and builds the assembly preview. Nothing is uploaded.
Import cut list
Loads a CSV or Frame Order Studio JSON into the tube table. A CSV needs item, length, and either outside size plus wall or a parseable description.
Download template
Saves frame-cut-list-template.csv with the supported column names and one example row.
Attach SLDPRT reference
Stores the selected part’s filename with the project. It does not parse SLDPRT geometry; import a STEP or a SolidWorks cut-list CSV for geometry or dimensions.
New order
After confirmation, clears the saved cut-list rows and part-file reference from this browser. Use Clear imported tubes separately to remove a loaded STEP and its linked rows.

STEP body and assembly buttons

Download all bodies + drawings ZIP
Creates a ZIP with one original STEP solid per file, a three-view SVG drawing for each body, the ballooned isometric assembly SVG, detected tube-spec CSV, and a README. Geometry is unchanged.
Download source alignment + cut audit ZIP
Creates an alignment and review handoff containing the original source STEP, individual source bodies, review-only drawings, cut-angle audit files, CSV, and CAD rework notes. It preserves the source geometry; it is not a corrected or approved manufacturing model.
Download STEP parts grouped by size + wall
Creates individual, unmodified STEP files in profile / outside-size / wall folders. Bodies missing specs go into Needs-Spec-Review; the ZIP also contains a folder index CSV.
Selected drawing SVG
Downloads the currently selected STEP body’s drawing as a vector SVG, named with its balloon number and detected tube type, size, and wall when available.
Print body sheets / PDF
Opens the browser print dialog with one drawing sheet per imported body. Choose “Save as PDF” in the print destination to make a PDF.
Clear imported tubes
Removes the loaded STEP, its body and assembly views, and rows linked to that STEP. Other cut-list rows remain.
Add bodies to tube set
Adds one editable tube row for each STEP body, carrying over detected profile, size, wall, bend flag, and body link where available. Cut length still needs entry or review.
Open selected tube sheet
Opens the tube-set editor for the selected body’s linked row.
Download assembly SVG
Saves only the fixed-isometric assembly drawing with numbered balloons and the part list as an SVG.
Assembly Print / PDF
Opens the landscape assembly sheet in the browser print dialog; select “Save as PDF” to make a PDF.

Tube set and order buttons

+ Add tube
Opens a blank tube form with a new item number and default round-tube fields. It does not add the row until you save it.
Save tube detail
Validates and saves the current item to this browser’s project data, then refreshes the table and drawing preview.
Save project JSON
Downloads frame-order-project.json with the saved rows and project metadata so the project can be imported later.
Download SVG drawing
Downloads the selected tube-set row’s planar centerline sheet as an SVG, including entered straight lengths, bend angles, centerline radii, and tube size / wall.
Tube Print / PDF
Opens one selected tube-set drawing in the browser print dialog. Use “Save as PDF” for a file.
Download BOM CSV
Saves frame-material-list.csv with item, quantity, profile, outside size, wall, approximate length, and bend count.
Print cut list / PDF
Opens the numbered cut-list sheet with quantity, tube size, reference length, and bend flag. Save it as PDF from the print dialog.
Print bend sheets / PDF
Opens sheets for saved rows that have valid bend legs, angles, and centerline radii. It reports an alert if no rows have complete bend data.
Before sending files to a manufacturerGeometry-envelope lengths and automatically inferred bend details can be approximate. Review tube size, wall, bend angle and radius, cut length, and end cuts in CAD. The hosted audit ZIP is a review handoff and does not modify or certify the STEP.
